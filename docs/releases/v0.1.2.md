# Octopus Roam v0.1.2

本版在 v0.1.1 基础上补充渠道兼容开关，修正批量刷新跟随行为，并完善界面和构建流程。正式程序、镜像、对应源码及校验和由 [v0.1.2 Release](https://github.com/Ink-lotus/octopus-roam/releases/tag/v0.1.2) 统一交付。

## 本版变化

- **自定义 Header“仅获取模型”。** 渠道高级设置的自定义 Header 标题右侧增加总开关，默认关闭。开启后，该渠道全部自定义 Header 仅用于手动获取、批量刷新和自动刷新模型，普通及流式 Relay 调用不再应用这些渠道自定义 Header；客户端透传 Header、渠道鉴权和参数覆盖继续按既有流程处理。关闭时沿用原有行为。开关随渠道保存，旧 API 调用方省略字段时保留已有设置。
- **清理 Responses 历史。** 新增按渠道保存、默认关闭的开关，仅处理最终发往 OpenAI Responses 的请求，且在参数覆盖后执行。开启时移除 `previous_response_id`、`include` 中的 `reasoning.encrypted_content`、`input` 内的 `id` / `encrypted_content` 及数组中的 `item_reference`，保留普通消息内容和工具调用关联字段。客户端需提供所需对话内容，不能仅依赖已清除的远端历史引用。发往其他协议的请求保持原有处理。
- **批量刷新遵守全局跟随。** 渠道页和分组页共用的任务只选择已启用且跟随全局更新的渠道；排队执行前再次核对，退出跟随者正常跳过。显式单渠道刷新、共享进度、防重入及展示筛选的行为保持。
- **界面与构建修复。** 统一渠道高级选项的开关和说明样式；前端构建保留已跟踪占位文件的原始字节，避免构建产生无关源码改动。
- **CI 和版本入口。** 普通 CI 根据完整变更范围区分文档检查与完整测试，持续提供必需的 `test` 状态；正式发布始终运行完整测试。程序、前端、默认本地构建和发布合同统一到 v0.1.2。

## 数据与备份

旧渠道的 `strip_responses_history` 与 `custom_header_model_only` 默认 false，由现有 AutoMigrate 增加；不新增编号迁移，已有 014/015、冷却规则、平台分类和分组归属保持。配置保存、缓存和备份均携带两个开关。

新导出为 `octopus-roam` 内容 **1003**，加密容器仍为 **1**。本版接受本产品 1000～1003，以及既有无产品标识的上游 0/5；继续拒绝无标识 6、外来产品和未知版本。规则和分类从 1001 起有效，Responses 开关从 1002 起有效，Header 开关从 1003 起有效；旧版本声明不能携带其尚不支持的启用状态。

同 ID 已有渠道的增量导入保留本地规则及两个开关，已有分组的分类保持；完整恢复使用空实例。v0.1.1 或更旧程序会拒绝 1003 备份，不能靠手改内容版本号实现降级。

## 升级、回滚与支持范围

升级前正常停止旧服务，保存旧程序、配置和完整数据快照；SQLite 保留完整数据目录及必要 WAL。v0.1.1 Windows 原生部署可使用既有更新助手；从 v0.1.0 的旧布局首次迁移仍需同时手动更新 exe 和 cmd。容器通过准确新镜像替换，保留数据挂载、旧容器和旧镜像，详见[升级说明](../upgrade-r1.md)。

回滚使用旧程序及升级前完整快照，不承诺旧程序直接读取新数据库；恢复旧快照会丢失升级后的新增数据。升级后核对实际程序/前端版本、渠道配置、两个开关默认值、持久化及备份恢复。

正式支持 Windows amd64 原生程序 / SQLite，以及 Windows / WSL Containers 3.0.3.0 / Linux amd64 镜像 / SQLite。其他原生平台、镜像架构、MySQL/PostgreSQL、Docker Engine/Compose 和反向代理维持实验性或范围外状态；可构建不等于正式支持。已有 [BUG-001](../known-bugs.md) 保留，个别渠道 Anthropic 模型探测的鉴权回退不在本版范围。

## 发布输入与交付

合同只接受 `v0.1.2` / `v0.1.2-rc.N`（N 为无前导零正整数），所有阶段绑定准确 commit、该 commit 中本说明的原始 Git blob 及 SHA-256。交付完整 11 个程序 ZIP、四架构镜像、应用与 Alpine 对应源码、声明、复建说明和统一校验和；准确身份见同一 Release 的 BUILD.json、MATERIALS.json、IMAGE-MANIFEST.json 及 SHA256SUMS。

固定工具及检查保持：Go 1.27.3、Node 24.18.0、pnpm 11.15.1、Python 3.14.6、NDK r28c。源码和前端重新生成；未变依赖来源仅在差异与哈希审查后复用。正式发布前完成本轮完整 CI、材料/产物核验、两个支持组合的升级与恢复以及原生更新助手验收，准确结果随发布记录保留；流程见[发布合同](../release-ci.md)和[材料入口](../release-materials.md)。
